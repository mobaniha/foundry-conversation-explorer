        Lab guide & troubleshooting
        
1. Select an account, a Foundry project, or paste its data-plane endpoint. The project is part of the URL, not a header or subscription ID.

        
2. Sign in with az login --tenant YOUR_TENANT_ID, or use an account API key. Entra requires appropriate data-plane RBAC and network access.

        
3. Choose List conversations (project scope), then Read items on a conversation. Or choose List conversation items and paste the conv_... ID you see in Foundry. No response ID is needed.

        
4. Read items opens the history oldest first. Use Next page or a cursor to read more. Back to conversations restores the fetched list page without another Azure call. Get conversation metadata reads the conversation container, not its messages.

        
5. Existing response tools still accept resp_... IDs. Get response shows generated output; List input items shows its submitted context. Response retrieval requires stored, unexpired data (normally 30-day retention); this is not a conversation retention rule.

        
401: key, tenant or token audience. 403: RBAC/project access or network restrictions. 404: wrong scope/ID, deleted conversation, unavailable route, or missing stored response. 429: respect Retry-After.

        
Request IDs and raw Azure error bodies are preserved. No automatic retries. Keys and results stay in memory only; downloaded JSON can contain sensitive conversation content.
